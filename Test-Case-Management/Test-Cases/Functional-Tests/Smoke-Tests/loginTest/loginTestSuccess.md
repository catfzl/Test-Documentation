### Login Test - Successful Login (Web App)
**ID:**

**Title:** Verify Successful login with valid credentials
*Description:* Manually verifies that a user can successfully log in to the web application when using valid credentials

*Preconditions:*
* A test user with valid credentials has been created and activated
* The Test user's email address is accessible to the Tester
* Tester has access to the testing environment

**Steps:**
1. Open web browser and navigate to the applications login page.
2. Enter test user's username in the `Username` field.
3. Enter test user's password in the `Password` field.
4. Click the login button.

**Expected Results:**
* User is redirected to the user's homepage or dashboard
* User specific information is displayed, indicating the login was successful
* No error messages displayed
