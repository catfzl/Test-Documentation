This assesses the user-friendliness and ease of use of the system from the end-user's perspective. This includes tests such as:

User Interface (UI) Testing: Evaluating the layout, design, and usability of the user interface.
Accessibility Testing: Ensuring that the system is accessible to users with disabilities and complies with accessibility standards.
User Experience (UX) Testing: Gathering feedback from users to assess their overall satisfaction and experience with the system.
