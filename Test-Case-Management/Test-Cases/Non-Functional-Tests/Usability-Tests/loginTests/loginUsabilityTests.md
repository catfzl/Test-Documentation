### Login Usability (UI) Test - Mobile Responsiveness
**ID:**

**Title:** Verify login screen responsiveness on different mobile devices
*Description:* Verifies that the login screen adapts correctly to different screen sizes and orientations on mobile devices.

*Preconditions:*
* The web app is deployed and running
* Mobile application installed of various mobile devices *Or* a access to a testing tool like Browserstack

**Steps:**
1. Open the mobile application on each test device.
2. Navigate to the login screen.
3. Rotate the device between portrait and landscape orientations.
4. Observe the layout and responsiveness of the login screen elements.

**Expected Results:**
* Login screen elements *(e.g., fields, buttons, labels)* are displayed correctly and are not truncated or overlapping
* The layout adapts to the screen size and orientation without any distortion or usability issues
